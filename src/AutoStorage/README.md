# Storage Rules

Right-click a storage container, machine, cage, or the trash can. The game menu gains a Storage rules row. That row opens the rules for that container only.

This mod does not read rules saved by the Workshop Auto Storage mod. Disable that copy so the two do not sort at once.

### How to use

- Right-click a container and choose Storage rules.
- The left side is the slot setup, then the categories and items you have allowed or blocked. Clear, copy, paste, and sort stay at the bottom.
- The right side is the picker. It starts with only the categories and items already in this container. Turn off Only what's in here to browse everything. Search is on the right.
- Click once to allow (green), again to block (red), and a third time to clear (gray). Item cells are the same size, with the icon above the name.
- An empty allow list accepts everything except blocked items. A fridge zone accepts nothing until you allow something.
- Accept stolen and Accept contraband start off. A smuggler bay (`smuggler_bay`, including the modded and large bays) starts with both on. A saved choice wins over that default.
- Higher priority is filled first. Machines are offered items before storage bays.
- Supply source sends what is inside onward. A storage page can receive and supply at the same time. Other slots use one role.
- Sort now, or use the sort hotkey. The master switch pauses every move.
- The trash can has two switches: animal feces, and bringing underground-exchange rewards back after sleep.

### Settings

- Open the Mods list, then click Settings on this mod.
- Sort and the master switch each have a hotkey. The default keys are Ctrl+R and Ctrl+Shift+O.

# 收纳规则 / Storage Rules

右键储物容器、机器、笼子或垃圾桶。游戏原来的菜单里会多出一行「入库规则」。点开的是这个容器自己的规则。

不会读取创意工坊 Auto Storage 存下的规则。那一份请先停用，避免两套同时整理。

### 怎么用

- 右键容器，选入库规则。
- 左边先是这个格子的开关，下面是已经收入或排除的类别和物品。清空、复制、粘贴和整理贴在底部。
- 右边是选择区，默认只列出这个容器里已有的类别和物品。关掉「只看这个容器里」才显示全部。搜索也在右边。
- 点一下收入（绿），再点排除（红），第三下清除（灰）。物品卡片一样大，图标在上、名字在下。
- 收入名单留空时，除了排除项都会收。冰箱的区留空则不收，需要先点允许的类别。
- 「接收赃物」和「接收违禁品」默认不勾选。暗格（`smuggler_bay`，含改装和大号）默认勾选。存过的选择会盖过这个默认。
- 优先级数字越大越先收。机器会比储物舱更早接到东西。
- 供给源会把里面的东西继续送出去。储藏页可以同时接收和供给，其他格子只能选一种。
- 点立即整理，或用整理快捷键。总开关关掉后，什么都不会移动。
- 垃圾桶只有两个开关：动物粪便，以及睡觉后把地下交易所的新物品拿回来。

### 设置

- 打开模组列表，点这个模组的设置。
- 整理和总开关各有一个快捷键。默认是 Ctrl+R 和 Ctrl+Shift+O。
